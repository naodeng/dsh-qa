- 状态页补了 Host adapter unavailable、provenance、409、403、无项目/无会话、loading/error、toast/confirm。
- 设计系统补了真实 ID 前缀、JSON 路径、Host adapter 语义、PASS/WARN/BLOCK 细节。

## 二、实现关键项（1 个）

### 1. `lg:h-[1024px]` 必须按 `data-stitch-vh` 映射成 `lg:h-screen`

静态稿仍是 1024 画布；1440×900 下实测：

```
copilot-input top = 978px
viewport height   = 900px
```

但 v5 已加标记：

```
data-stitch-vh="min-h-[1024px]===min-h-screen|||lg:h-[1024px]===lg:h-screen"
```

说明设计意图是把 1024 映射成 `h-screen`。**实现时必须应用这个映射，并在 900/768 下验收；如果工具不应用，就仍然是 P0。**

## 三、P1 收口项

### 1. 英文仍是「半支持」

v5 给日历/看板/移动端都加了语言切换，`data-i18n` 覆盖提升到：

| 页面 | 数量 |
| --- | --- |
| 首页 | 32 |
| 工作区 | 32 |
| 设置 | 24 |
| 看板 | 25 |
| 日历 | 26 |
| 移动端 | 22 |
| Skills | 19 |
| 状态页 | 12 |

但表头、表单标签、状态、空态、错误、弹窗仍大量硬编码中文；没有一张完整英文页面。需要补完整英文文案表或至少 4 个桌面页 + 移动端 + 关键弹窗的英文截图。

### 2. 设置里的 DSH 版本和官网是错的

- `兼容 DSH: v0.7.x`：`v0.7.x` 是 dsh-qa 的版本，不是 DSH。当前 `dsh-v0.2.0-rc.2`，README 验证过 v0.2.2-rc.1。
- `官网 (dsh.dev)`：项目官网是 `https://inaodeng.com/zh-cn/dsh-qa/`，不是 dsh.dev。
- `项目主页 (Homepage)`、`代码仓库 (Repository)` 还是 `#`。

### 3. 对话还缺完整「技能与命令」和「辅助策略」

- 右栏 slash 菜单只有 `/api-testing`、`/test-strategy` 两条；当前有完整 `openDshCapabilities`：技能/命令 tab + 搜索。
- 右栏只显示「策略：全流程主动协作」，没有「调整辅助策略」入口；当前 composer 有。
- 会话恢复只有「会话已连接」切换 banner，没有缺失/未绑定/需要新对话/列表不可用四种状态。
- 模型下拉是「当前默认模型（来自 DSH 目录）」占位，不是真实模型列表。

### 4. Skills 还有 3 个不存在的技能 + 设计验收控件

- `regression-testing`、`exploratory-testing`、`ui-automation` 在真实目录不存在；其余 7 个存在。
- 顶部「加载中 / 加载失败 / 空结果」是设计验收控件，交付前应移除或标「设计验收用」。
- `查看 Skill 详情` 已打开 modal，但内容还是占位；需要接真实 siteUrl/描述。
- 加载/失败/空态已有，保留。

### 5. 首页「需要你处理」没有跨项目行动台

「需要你处理 (3)」有两类项目（PRJ-2026-001、ITER-2026-0301），但只有「进入工作区处理 →」跳单个项目。当前版本有「打开行动台」跨项目列表。需要补一个行动台/drawer，或在每行提供对应项目的直接动作。

### 6. 看板卡片/首页快速预览仍可补

- 看板卡片只显示需求/用例/缺陷/里程碑 4 个计数；当前还有报告/待审批门禁/AI 进行中/最近活动。
- 首页「快速预览」打开的是摘要 drawer（阶段/计数/门禁），不是看板的 10 tab drawer；如果保留「快速预览」这个名字，建议复用 10 tab，或改名「摘要」。

## 四、P2 收口项

- `fa_01` 应为 `failure_*`；`reg_order_core` 应为 `regression_*`；`dec_01` 是设计自造 ID，现有 decisions 没有独立 ID。
- 移动端证据卡 `passed · block` 仍会让人误读；建议移动端也把「结果」和「级别」拆开，或只在 failed 时显示严重度。
- 设置/工作区的 modal 有 focus/restore，但没有 focus trap；交付前补上。
- `components/` 目录仍不存在；设计系统引用 `@components/*.html`，实现者只能从页面反推。
- 字体仍是 Google Fonts Red Hat/Instrument Sans（中文回退）+ Tailwind CDN；本地/离线需要系统字体或本地 woff2 + 手写 CSS。
- 交付前去掉 `data-stitch-vh`、`预览模态弹窗`、Skills 状态预览等原型/设计工具控件。
