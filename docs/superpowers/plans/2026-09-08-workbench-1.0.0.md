# DSH QA Workbench 1.0.0 Implementation Plan（稳定工作台）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 0.6–0.9 收口为可日常依赖的 1.0——主路径打磨、空状态与错误恢复、新项目向导、迁移/文档/版本齐套。

**Architecture:** 以产品化与测试加固为主，原则上不新增领域实体；向导状态可用 `localStorage`；版本号与 README 对齐 `1.0.0`。

**Tech Stack:** 既有栈；Playwright E2E 加强。

**Spec:** 需求 §5.5；getting-started §4–5。
**Depends on:** 0.6–0.9 范围已验收（允许已知小问题列入 1.0 修复清单，但不得缺整版主题）。

## Global Constraints

- 少加功能，多修体验与文档。
- 不把后置项（MCP/CI Gate/RBAC）塞进 1.0 必达。
- 发布门槛：`npm test` + `git diff --check`。

### Task 1: End-to-end main path E2E

**Files:** Create/extend `test/e2e/workbench-main-path.spec.js`

覆盖最小闭环（独立模式能测的部分 + 可 mock 的导航）：

1. 首页行动队列可见
2. 进入项目详情
3. 打开助手视图（独立模式断言降级文案）
4. 打开门禁/质量相关 Tab（若有数据则用 API 种子）

- [ ] 实现并稳定（减少 flake：显式 wait、不依赖真实模型）
- [ ] Commit `test: e2e main path for workbench 1.0`

### Task 2: Empty states, error recovery, glossary hints

**Files:** `public/app.js`, `public/index.html`, `public/style.css`, `public/i18n.js`

- [ ] 队列空、矩阵空、门禁无结论、Skills 未配置等空状态有下一步指引。
- [ ] 关键请求失败时页面内可见恢复动作（重试/回到首页）。
- [ ] 关键术语（如 PASS/WARN/BLOCK、受控执行）提供简短说明（title 或帮助抽屉，中英）。
- [ ] Commit `fix: empty states and error recovery copy`

### Task 3: First-run onboarding wizard

**Files:** `public/*`

- [ ] 轻量多步：创建/选择项目 → 打开对话或质量任务 → 查看门禁；可跳过。
- [ ] 状态键如 `localStorage['dsh-qa.onboarding.v1'] = 'done'|'skipped'`。
- [ ] E2E：`test/e2e/onboarding.spec.js` 可跳过且不阻塞主路径。
- [ ] Commit `feat: first-run workbench onboarding`

### Task 4: Docs, version metadata, migration sanity

**Files:** `package.json` version、`README.md` / `README_EN.md`、`AGENTS.md`（若需）、可选 `CHANGELOG.md`、`docs/quality-workbench/*`

- [ ] 版本号 `1.0.0`；README 功能列表反映 0.6–1.0 能力与「如何开始」链接。
- [ ] 若本路线有 schemaVersion bump：补迁移幂等测试；无 bump 则跑既有 `migrations` 测试确认绿。
- [ ] 新增 `docs/quality-workbench/2026-09-08-implementation-status.md` 记录 0.6–1.0 完成边界（可在本 Task 撰写）。
- [ ] Commit `docs: release workbench 1.0.0`

### Task 5: Release DoD
