# DSH QA Workbench 0.8.0 Implementation Plan（变更与回归）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 QA「知道测什么」——变更摘要生成可确认的测试范围/回归集草稿，缩短回归执行预览路径，看板展示覆盖/风险徽标。

**Architecture:** `server/quality/change-impact.js` 只产草稿；preview/apply API；apply 时校验 `inputDigest` 再写 `testScope` 或 `createRegressionSet`；看板投影只读徽标。

**Tech Stack:** Node ESM、既有 `source.js` / `regression.js`、原生前端、`node:test`、Playwright。

**Spec:** technical-design §5；需求 §5.3。  
**Depends on:** 0.6；建议 0.7 已合入。

## Global Constraints

- 草稿绝不自动落库为回归集。
- 复用 git-diff 来源大小/UTF-8 限制；不改用户仓库文件。
- 启发式可简单，但必须稳定可测（固定夹具路径关键词）。

### Task 1: `buildChangeImpactDraft` unit tests

**Files:**
- Create: `server/quality/change-impact.js`
- Create: `test/unit/change-impact.test.js`
- Reuse: `server/quality/source.js`（可对采集函数注入假 snapshot）

- [ ] **Step 1: Failing tests**

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { buildChangeImpactDraftFromSnapshot } from '../../server/quality/change-impact.js';

test('maps payment path keywords to matching test cases', () => {
  const project = {
    id: 'project_1',
    workspacePath: '/tmp/ws',
    testcases: [
      { id: 'tc_pay', title: '支付回调验签', module: '支付' },
      { id: 'tc_other', title: '登录', module: '账号' },
    ],
    requirements: [{ id: 'req_1', title: '支付回调' }],
  };
  const draft = buildChangeImpactDraftFromSnapshot(project, {
    ref: 'HEAD~1..HEAD',
    digest: 'sha256:abc',
    snapshot: 'diff --git a/server/pay/callback.js b/server/pay/callback.js\n+fix',
    capturedAt: '2026-09-08T00:00:00.000Z',
  });
  assert.equal(draft.inputDigest.startsWith('sha256:'), true);
  assert.ok(draft.suggestedTestCaseIds.includes('tc_pay'));
  assert.ok(draft.suggestedTestScope.length >= 1);
});
```

- [ ] **Step 2–4:** 实现基于路径/标题关键词的启发式 + digest → PASS → Commit `feat: change impact draft builder`
