# DSH QA Workbench 0.6.0 Implementation Plan（行动台，历史草案）

> **已被替代：** 当前 `0.6.0` 是 Native QA Execution，计划见 `2026-09-15-workbench-0.6.0.md`。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** QA 打开工作台即可看到「需要你处理」队列，质量事件实时刷新，详情可一键跳对话/门禁/证据，Skills 路径可配置。

**Architecture:** 新增纯函数聚合模块 `server/action-queue.js`；`GET /api/action-queue` 暴露；前端首页以队列为主焦点并订阅质量 SSE；Skills 根目录文档化环境变量并校验。

**Tech Stack:** Node.js ESM、JSON store、SSE、原生前端、`node:test`、Playwright。

**Spec:** `docs/quality-workbench/2026-09-08-technical-design.md` §3；需求 §5.1。

## Global Constraints

- 不改变门禁/证据 PASS 规则。
- 行动项只读聚合，不写 store。
- 队列条数默认上限 50；稳定 `id` 便于去重。
- 中英文同步；独立模式可用。

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { buildActionQueue } from '../../server/action-queue.js';

test('orders high priority gate_block before low milestone_due', () => {
  const now = new Date('2026-09-08T00:00:00.000Z');
  const projects = [{
    id: 'project_1', title: 'Pay',
    milestones: [{ id: 'ms_1', title: 'UAT', dueAt: '2026-09-10T00:00:00.000Z' }],
    gates: [{ id: 'gate_1', kind: 'computed', verdict: 'BLOCK', status: 'evaluated' }],
    testruns: [], qualityTasks: [],
  }];
  const { items } = buildActionQueue(projects, { now, limit: 50 });
  assert.equal(items[0].kind, 'gate_block');
  assert.equal(items[0].projectId, 'project_1');
  assert.ok(items[0].id.includes('gate_1'));
});

test('includes failed controlled runs and confirmation tasks with open critical risk', () => {
  const now = new Date('2026-09-08T00:00:00.000Z');
  const projects = [{
    id: 'project_2', title: 'X',
    milestones: [], gates: [],
    testruns: [{ id: 'run_1', status: 'failed', resultTrust: 'controlled-local' }],
    qualityTasks: [{
      id: 'qt_1', stage: 'confirmation',
      risks: [{ id: 'r1', severity: 'critical', dispositionStatus: 'open', assessmentStatus: 'confirmed' }],
    }],
  }];
  const kinds = buildActionQueue(projects, { now, limit: 50 }).items.map((i) => i.kind);
  assert.ok(kinds.includes('run_failed'));
  assert.ok(kinds.includes('quality_task_confirm'));
});
```
